# TaxiNow V1.0 Beta

## English

This is the first public beta release of TaxiNow.

- Displays downloaded airport ground maps and the aircraft's live ground
  position from Microsoft Flight Simulator.
- Officially supports Microsoft Flight Simulator 2024.
- Microsoft Flight Simulator 2020 may work, but official support will be added
  in a later release.
- Includes the Windows installer and a portable ZIP package.

TaxiNow is free for personal, non-commercial flight-simulation use and is
provided **“AS IS”**, without warranties of any kind. It must not be used for
real-world navigation. Please read the repository introduction, license, EULA,
and disclaimer before installation.
