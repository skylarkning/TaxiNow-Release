# TaxiNow V1.0 Beta 2

## English

> **Important:** Uninstall TaxiNow V1.0 Beta before installing Beta 2. The
> uninstaller removes downloaded map assets, so those maps must be downloaded
> again after installation.

### Short changelog

- Filters local catalog identifiers that are not valid ICAO airport codes.
- Fixes X-Plane Gateway source revision errors affecting airports such as ZBCZ.
- Skips an individual broken airport during a country/region download instead
  of failing the entire batch.
- Shows skipped-airport warnings when a batch completes.

TaxiNow is free for personal, non-commercial flight-simulation use and is
provided **“AS IS”**, without warranties of any kind. It must not be used for
real-world navigation. Please read the repository introduction, license, EULA,
and disclaimer before installation.

## 中文

> **重要：**安装 Beta 2 前，请先卸载 TaxiNow V1.0 Beta。卸载程序会删除已下载的
> 地图资源，因此安装完成后需要重新下载地图。

### 简短更新日志

- 过滤并非有效 ICAO 机场代码的本地目录编号。
- 修复 ZBCZ 等机场的 X-Plane Gateway 来源版本号错误。
- 国家/地区批量下载中，单个机场出错时会自动跳过，不再导致整个任务失败。
- 批量下载完成后会显示被跳过机场的警告。

TaxiNow 完全免费，仅供个人、非商业模拟飞行使用，并按“现状”提供，不作任何形式的担保。
严禁用于真实飞行导航。安装前请阅读仓库介绍、许可协议、最终用户许可协议及免责声明。
