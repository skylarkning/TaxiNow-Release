# TaxiNow V1.0 Beta 2

## English

TaxiNow V1.0 Beta 2 fixes country/region map download failures discovered in
the first beta build.

- Displays downloaded airport ground maps and the aircraft's live ground
  position from Microsoft Flight Simulator.
- Officially supports Microsoft Flight Simulator 2024.
- Microsoft Flight Simulator 2020 may work, but official support will be added
  in a later release.
- Includes the Windows installer and a portable ZIP package.
- Filters local catalog identifiers that are not valid ICAO airport codes.
- Normalizes numeric source revisions used by some X-Plane Gateway maps,
  including ZBCZ.
- Skips an individual broken airport during a country/region download instead
  of failing the entire batch, and reports the skipped item as a warning.

TaxiNow is free for personal, non-commercial flight-simulation use and is
provided **“AS IS”**, without warranties of any kind. It must not be used for
real-world navigation. Please read the repository introduction, license, EULA,
and disclaimer before installation.

## 中文

TaxiNow V1.0 Beta 2 修复了首个测试构建中发现的国家/地区地图下载问题。

- 显示已下载的机场地面地图，并从 Microsoft Flight Simulator 获取飞机的实时地面位置。
- 正式支持 Microsoft Flight Simulator 2024。
- Microsoft Flight Simulator 2020 可能可以使用，但正式支持将在后续版本中加入。
- 提供 Windows 安装程序和便携版 ZIP 压缩包。
- 过滤并非有效 ICAO 机场代码的本地目录编号。
- 将部分 X-Plane Gateway 地图使用的数字来源版本号转换为标准字符串，包括 ZBCZ。
- 国家/地区批量下载中，单个机场出现问题时将跳过该机场并显示警告，不再导致整个任务失败。
