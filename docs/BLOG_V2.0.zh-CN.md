# TaxiNow Pro V2.0：从机场滑行，到看清整段飞行

发布日期：2026年10月3日 · Build 207

TaxiNow 正式更名为 **TaxiNow Pro**。V2.0 将机场地面地图、航线浏览和垂直剖面串在一起：出发前导入计划，在地球视图中查看航路，飞行中结合交通、天气和地形理解当前位置，落地后再回到机场滑行地图。原有的地面功能继续保留，而这次更新让整个飞行过程有了更完整的视图。

## 新的航线工作区

启动后的默认页面现在是航线地球视图。你可以在 2D 与 3D 之间切换，缩放查看整个旅程或某一段航路，通过左上角的指南针恢复正北朝上。需要查看机场地面时，使用左侧的“地面”按钮切换；垂直剖面则有独立入口，不会在启动时遮住地图。

顶部原来的两行工具栏合并为一行，“飞行计划”和“航路信息”放在右侧。机场名称显示在航班号旁边，左侧机场按钮显示当前 ICAO 四字代码并可直接选择机场。地图来源、版权链接及状态信息合并到底部，给地图留出更多空间。

## 从 SimBrief 开始下一段飞行

导入 SimBrief 计划后，航线、航路点、机型和计划高度可在同一工作区查看。飞行计划面板提供完整航路适配操作，航路信息面板列出航路点及坐标；两个面板采用一致的样式、尺寸和展开动画。“清除计划”移动到“导入”旁边，方便重新开始，SimBrief 用户名也会自动保存在当前浏览器中。

程序会尝试下载计划中的出发及到达机场地图，并在落地后切换到目的地地面地图。下载仍取决于网络和机场数据源；没有地图时，可以打开地图管理查看状态或手动处理。

## 从侧面查看航线：垂直剖面

V2.0 新增全屏垂直航线剖面。横轴展示沿航线的距离，纵轴展示高度，地形轮廓与计划高度路径一起呈现，让爬升、巡航和下降阶段更容易理解。导入计划包含高度限制时，会显示对应标记；缺失数据时生成的估算路径会明确标注，不会当作公布的高度限制。

模拟器提供有效遥测时，剖面显示飞机沿航线的位置、海拔高度及可用的离地高度，并展示地形间隔、下一高度限制和到目的地的距离等信息。遥测失效后会清除实时飞机显示，避免把过期位置继续当作当前状态。地形和计划数据并不等于实时导航或地形告警设备，本功能仅供模拟飞行使用。

## 交通、天气与空域信息

航线地图加入 VATSIM 管制信息及飞机交通、天气雷达、GNSS 干扰图层和地形显示，各图层可按需要切换。VATSIM 飞机在亮色和暗色模式中都使用橘色，呼号标签保持清晰。VATSIM 网络数据按官方数据源的更新节奏刷新，不是逐帧的即时位置。

BeyondATC 与 SayIntentions 交通显示继续保留，使用时可在设置中选择对应来源。不同交通来源互斥，避免重复叠加。天气、交通及 GNSS 图层的可用性和新鲜度取决于外部服务，不应视为完整、实时的运行保障信息。

## 支持 X-Plane 12，也继续支持 MSFS

Windows 桌面端支持 Microsoft Flight Simulator 2020、Microsoft Flight Simulator 2024 和 X-Plane 12。X-Plane 12 通过本机 UDP DataRef 接口提供位置、航向、地速、地面状态和高度，默认端口为 49000；运行时请将模拟器与 TaxiNow Pro 放在同一台电脑上。

这里的 X-Plane 12 遥测支持与 X-Plane Scenery Gateway 地图来源是两件独立的功能。前者提供飞机状态，后者为机场地图提供后备数据。

## 更可靠的跟随与机场下载

飞机跟随现在同时处理位置和航向，改善了滑行中飞机驶出可见范围却没有继续跟进的问题。航线视图也支持持续跟随飞机；图标和定位操作同步重新整理，让用途更直观。

机场下载长时间没有进展或失败时，地图管理提供“尝试后备资源”操作。点击后会跳过 OSM 和地图包，尝试 X-Plane Scenery Gateway；必要时以 OurAirports 作为最终跑道数据后备来源。后备数据的细节可能不同，部分机场只有基础跑道信息，不能保证与原始来源完全一致。

## 让亮色和暗色都真正可用

新版界面的主题覆盖顶部、侧栏、底部、地图工具和弹出菜单。亮色模式中的机场名称、模拟器状态、地图摘要等文字改用更清晰的深色，暗色模式保持足够对比度。按钮尺寸和圆角统一，加减号居中，机场选择按钮去掉多余箭头，设置菜单恢复滚动。

设置按钮旁恢复太阳/月亮快捷切换。桌面 WebView2 使用 sRGB 色彩配置，处理部分显示环境中界面泛黄的问题。最小化默认回到任务栏；希望隐藏到托盘的用户可以在设置中开启“最小化到托盘”。

## 移动设备、反馈与更新

电脑端运行时，手机和平板可以通过顶部显示的局域网地址打开同一界面，设备须连接同一局域网。建议基线为 Android 10 及以上、Firefox 114 及以上，或 iOS/iPadOS 16.4 及以上的 Safari，同时需要浏览器和 GPU 支持 WebGL 2.0。FAQ 已加入这些要求以及 X-Plane 12 的连接说明。

设置中的“报告问题”直接打开 GitHub 表单，可选择 Bug Report 或 Feature Request，并填写 Summary、联系方式、问题描述和预期结果。请注意表单内容公开可见。

更新弹窗现在根据检查结果显示新版本、已是最新版或检查失败，不再出现互相矛盾的标题和空白发行说明框。应用内下载过的安装包可通过“打开更新安装包目录”手动清理；程序不会自动删除文件。

## 升级到 V2.0

关闭 TaxiNow / TaxiNow Pro 后运行 `TaxiNow-Pro-V2.0-Build-207-Setup.exe`，可以覆盖安装旧版本。安装目录和用户数据标识保留兼容性，旧快捷方式会迁移为 TaxiNow Pro；如先卸载旧版本，请选择保留地图和用户数据。

高级用户也可以下载 `TaxiNow-Pro-V2.0-Build-207-Portable.zip`，解压后运行其中的 `TaxiNow.App.exe`。Portable 使用相同的程序，但不会提供安装器的快捷方式、卸载与前置运行环境检查；地图数据也不会自动存放在解压目录里。
